# Aqua Stasis Regulator(ASR)
Smart real-time hydroponics monitoring and alert system using Arduino

## Overview

Aqua Stasis Regulator continuously monitors critical hydroponic parameters and alerts the user when values move outside their safe ranges.

## Monitored Parameters

- pH
- Electrical Conductivity (EC)
- Dissolved Oxygen (DO)
- Water Temperature
- Reservoir Water Level

## Features

- Real-time parameter monitoring
- Out-of-range alerts
- Web-based monitoring
- Actionable corrective suggestions
- Continuous monitoring of hydroponic water conditions

## Hardware

- Arduino
- pH Sensor
- EC Sensor
- Dissolved Oxygen Sensor
- Temperature Sensor
- Water Level Sensor
- Voltage Regulator
- Power Supply
